# Internal shadow-review page

## What you get

A single dark page listing mail the filter **would flag** (shadow) or already scored over threshold: time, account, score, subject, sender. Auto-refresh. No mailbox actions.

Access path (you own DNS + Caddy):

```text
Browser (on NetBird) → imap.bytelord.net → Caddy on ByteLord → 127.0.0.1:8090 → web container → SQLite
```

**DNS:** A record for `imap.bytelord.net` must be ByteLord’s **NetBird** address, not the public WAN IP. Anyone can look up the name; only NetBird peers can route to it.

**Caddy:** reverse_proxy to `127.0.0.1:8090`, not `file_server` of a folder. The page is generated from a live DB, so Caddy cannot just serve static files from the repo.

No extra login. NetBird routing + loopback-only Docker publish is the gate (same pattern as [gitea compose](/opt/bytelord/compose/gitea/compose.yaml) `127.0.0.1:3000`). Leave the existing Flask dashboard on `127.0.0.1:8080` unused unless you want it later.

## Data (SQLite, not docker logs)

Filter already writes the decision into [`filter/filter.py`](filter/filter.py) (`our_action="shadow"` plus `[shadow] would flag` in stdout). Query [`/opt/bytelord/data/imap-spamfilter/state/spamfilter.db`](/opt/bytelord/data/imap-spamfilter/state/spamfilter.db) (WAL; safe to read while the filter runs).

Default list: `our_action IN ('shadow','flagged','pending_move')` **or** `our_score >= 8` (threshold default). Highlight by score (e.g. >=15 strong, >=8 warn). Toggle `?all=1` for every scored message.

## Layout

New subdirectory [`web/`](web/) in imap-spamfilter (not inside `filter/`):

- [`web/app.py`](web/app.py) — stdlib `http.server` + `sqlite3` (no Flask). Bind `0.0.0.0:8090` in-container; compose publishes **`127.0.0.1:8090:8090`**.
- [`web/page.html`](web/page.html) — dark background (`#111` / light-on-dark table); one table; meta refresh ~15s.
- [`web/Dockerfile`](web/Dockerfile) — `python:3.12-slim`, uid 1001, read-only mount of state dir.
- Tests: [`web/test_app.py`](web/test_app.py) against a temp SQLite with a shadow row.

## Compose

Add service `spamfilter-web` to [`deploy/bytelord-compose.yaml`](deploy/bytelord-compose.yaml) (copy to live compose):

- `build: …/imap-spamfilter/web`
- volume: `/opt/bytelord/data/imap-spamfilter/state:/state:ro`
- `STATE_DIR=/state`
- `networks: [spamnet]`
- **no** public `0.0.0.0` publish

Same container-per-process rule as the OAuth proxy.

## Caddy (you edit)

Snippet for your Caddyfile (we will not edit it unless you point us at the path):

```caddy
imap.bytelord.net {
    bind <netbird-ip>   # or rely on firewall if Caddy already NetBird-only
    reverse_proxy 127.0.0.1:8090
}
```

HTTP is enough on the overlay; add `tls internal` only if you already do that for other `*.bytelord.net` names.
